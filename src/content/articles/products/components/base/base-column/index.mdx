Groupboxの旧名称です。BaseColumnはGroupboxに名称変更されました。

機能やPropsは同じで、コンポーネント名だけが変わっています。使い方は[Groupbox](/products/components/groupbox/)を参照してください。

```tsx
// 変更前
import { BaseColumn } from 'smarthr-ui'

<BaseColumn>...</BaseColumn>

// 変更後
import { Groupbox } from 'smarthr-ui'

<Groupbox>...</Groupbox>
```
