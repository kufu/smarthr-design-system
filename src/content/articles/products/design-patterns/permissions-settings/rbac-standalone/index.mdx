共通設定の権限とは切り離し、プロダクト独自にアカウントごとに権限を付与するパターンを説明します。

## 用語

このパターンで扱う用語の定義です。

| 用語 | 説明 |
|:---|---|
| 権限 | アカウントに付与するプロダクトの操作の許可のことです。権限は、アカウントに関連づける要素（操作の権限、ロール、独自の設定項目）の組み合わせで表します。 |
| 要素 | 権限を構成する各部品のことです。 |
| 構成 | 要素の組み合わせです。ロールの有無、操作の権限の種類、独自の設定項目の有無で表します。 |

## 要素

権限がどのような要素で構成されるかを説明します。

- [アカウント](#h3-0)
- [操作の権限](#h3-1)
- [ロール](#h3-2)
- [独自の設定項目](#h3-3)

### アカウント

「アカウント」とは権限を付与する対象です。メールアドレスアカウントまたは社員番号アカウントが該当します。

テナントの従業員全員ではなく一部の管理者にだけ権限を付与するようなプロダクトでは、管理者権限を持つことを明確に認知させるため、アカウントを「管理アカウント」と呼び替えても構いません。

### 操作の権限

アカウントがプロダクトでどんな操作をできるかを決めるものです。アカウントに対して1つだけ設定できます。

#### 操作の権限の種類

操作の権限は、プロダクトがあらかじめ定義した操作の権限（プリセット操作権限）と、それに加えてユーザーが作成した操作の権限（カスタム操作権限）があります。

カスタム操作権限を扱えるプロダクトでは、プリセット操作権限も同列で扱えるようにしてください。プリセット操作権限は、カスタム操作権限の作成時のひな形として使っても構いません。

また、どちらの場合でもアカウントに設定できる操作の権限は1つです。

### ロール

アカウントがプロダクト内で閲覧できる従業員情報の範囲を絞るためのものです。共通設定のロールから1つ選択し、アカウントに設定します。

<InformationBlock marginTop="1">
  <p style="margin-top: 0">ここで扱っている「ロール」は、一般名詞としてのロール（役割）やRBACが示す `Role` ではなく、**SmartHR基本機能の共通設定で管理している「ロール」のこと**です。</p>
</InformationBlock>

### 独自の設定項目

操作の権限とロール以外で、プロダクトが管理する特定のオブジェクトについて、アカウントごとに閲覧や操作できる範囲を絞るためのプロダクト固有の設定項目です。

プロダクト全体に適用する表示設定や通知設定など、アカウントと関係なく決まる設定は、独自の設定項目には含みません。

独自の設定項目を持つプロダクトでの具体は以下の項目が該当します。

- 社内公募:`操作できる範囲`
- 採用管理:`閲覧できる応募の範囲`
- キャリア台帳:`従業員情報の表示設定`、`タレントタグの表示設定`、`メモの表示設定`

## 構成

RBACの独自権限パターンでは、「アカウント」と「操作の権限」は必須の要素です。ロール・カスタム操作権限・独自の設定項目は、プロダクトの要件に応じて追加します。

### ロールなし

プロダクトがロールで閲覧範囲を制御しない場合です。閲覧範囲の制御が不要なプロダクトや、そもそも従業員情報を扱わないプロダクトが該当します。

| <span style={{ whiteSpace: 'nowrap' }}>カスタム操作権限</span> | <span style={{ whiteSpace: 'nowrap' }}>独自の設定項目</span> | <span style={{ whiteSpace: 'nowrap' }}>対象プロダクト</span> |
|:---|:---|:---|
| - | - | &lt;ESP・情シスのプロダクト名&gt; |
| - | ◯ | 社内公募 |
| ◯ | ◯ | 採用管理 |

### ロールあり

プロダクトがロールで閲覧範囲を制御する場合です。タレントマネジメントプロダクトのほとんどが該当します。

| <span style={{ whiteSpace: 'nowrap' }}>カスタム操作権限</span> | <span style={{ whiteSpace: 'nowrap' }}>独自の設定項目</span> | <span style={{ whiteSpace: 'nowrap' }}>対象プロダクト</span> |
|:---|:---|:---|
| - | - | 従業員サーベイ、配置シミュレーション、スキル・資格・研修、HRアナリティクス |
| ◯ | - | 人事評価 |
| - | ◯ | キャリア台帳 |
| ◯ | ◯ | 現状は対象プロダクトなし |
