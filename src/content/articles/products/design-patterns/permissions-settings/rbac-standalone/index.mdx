共通設定の権限とは切り離し、プロダクト独自にアカウントと権限を紐づけて管理するパターンの画面構成をまとめています。分類の考え方は[権限設定](/products/design-patterns/permissions-settings/)を参照してください。

## 用語

このパターンでは、用語を次のように使い分けます。

| 用語 | 説明 |
|:---|---|
| 要素 | 権限設定画面を構成する部品です。「アカウント」「操作の権限」「共通設定のロール」などを指します。 |
| 構成 | 要素の組み合わせです。「基本構成＋ロール」のように表します。 |
| 画面パターン | 構成ごとの画面の設計です。[一覧画面](/products/design-patterns/permissions-settings/rbac-standalone/collection/)と[詳細画面](/products/design-patterns/permissions-settings/rbac-standalone/single/)があります。 |

「権限」と呼ぶのは、アカウントにつける「操作の権限」だけです。それ以外の要素は「権限」と呼びません。

### アカウントと管理アカウント

権限を付与する対象を「アカウント」と呼びます。メールアドレスアカウントまたは社員番号アカウントのことです。

従業員全員ではなく、一部の管理者にだけ権限を付与するプロダクトでは、「管理アカウント」と呼んでも構いません。

### 共通設定のロール

このパターンで扱う「ロール」は、SmartHR基本機能の共通設定にある「ロール」のことです。一般名詞としてのロール（役割）や、RBACが説明する `Role` とは異なる概念なので注意してください。

## 要素

独自権限パターンの権限設定画面は、必須の「基本構成」に、必要な要素を加えて構成します。

| 要素 | 説明 |
|:---|---|
| <span style={{ whiteSpace: 'nowrap' }}>基本構成（必須）</span> | 「アカウント」と「操作の権限」の組み合わせです。操作の権限は、プロダクトがあらかじめ定義した固定のものです（例：「業務担当者」「機能管理者」）。 |
| <span style={{ whiteSpace: 'nowrap' }}>＋ロール</span> | 共通設定のロールを使い、アカウントが閲覧できる従業員の範囲を絞ります。 |
| <span style={{ whiteSpace: 'nowrap' }}>＋操作の権限の管理</span> | ユーザーが操作の権限を追加・編集できるようにします。プロダクトがあらかじめ定義した操作の権限も含みます。一覧画面に「操作の権限」タブが増えます。 |
| <span style={{ whiteSpace: 'nowrap' }}>＋独自の設定項目</span> | 操作の権限とは別に、プロダクトごとに追加する項目です。タレントタグの表示や従業員情報の表示設定なども含みます。一覧画面にタブが、詳細画面に入力欄が増えます。 |

## 構成

基本構成に加える要素の組み合わせにより、独自権限パターンは次のように分類できます。

| 構成 | 対象プロダクト | ガイドライン |
|---|---|:---:|
| 基本構成のみ | ロールを利用しないプロダクト | － |
| 基本構成＋ロール | 従業員サーベイ、配置シミュレーション、スキル・資格・研修、HRアナリティクス | ○ |
| 基本構成＋ロール＋操作の権限の管理 | 人事評価 | ○ |
| 基本構成＋ロール＋独自の設定項目 | キャリア台帳 | ○ |
| 基本構成＋ロール＋操作の権限の管理＋独自の設定項目 | 対象プロダクトなし | － |
| 基本構成＋独自の設定項目 | 社内公募 | － |
| 基本構成＋操作の権限の管理＋独自の設定項目 | 採用管理 | － |

{/* 「基本構成のみ」の既存ガイドラインの置き場所が確定したら、上の表または本文からリンクしてください */}

このページの一覧画面・詳細画面では、「基本構成＋ロール」を基本に、「操作の権限の管理」「独自の設定項目」を加えたときに画面がどう変わるかを説明します。ロールを利用しない構成は、独自の設定項目が複雑なものが多いため、現時点ではガイドライン化していません。
