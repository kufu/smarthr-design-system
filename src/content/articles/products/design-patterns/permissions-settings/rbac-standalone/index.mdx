共通設定の権限とは切り離し、プロダクト独自にアカウントと権限（役割）を紐づけて管理するパターンの画面構成をまとめています。分類の考え方は[権限設定](/products/design-patterns/permissions-settings/)を参照してください。

## 構成要素

独自権限パターンの権限画面で扱う主要なプロパティを①〜④に呼び分けます。

| プロパティ | 説明 |
|:---|---|
| <span style={{ whiteSpace: 'nowrap' }}>①基本権限</span> | 「アカウント」「ロール」「操作の権限」の3つのプロパティをまとめたものです。<br />・アカウント：メールアドレスアカウントまたは社員番号アカウント<br />・ロール：SmartHR基本機能の共通設定にある「ロール」のこと<br />・操作の権限：システムプリセットのみ（例：「業務担当者」「機能管理者」） |
| <span style={{ whiteSpace: 'nowrap' }}>②カスタム操作権限</span> | プロダクトの操作の権限がユーザーによって自由に設定できる場合のものです。システムプリセットを含みます。 |
| <span style={{ whiteSpace: 'nowrap' }}>③独自オブジェクト権限</span> | ①②以外の独自のオブジェクト権限です。プロダクト内で作成・管理しているかどうかは問わず、権限設定画面で扱われていれば対象とします。 |
| <span style={{ whiteSpace: 'nowrap' }}>④ロールのない基本権限</span> | アカウントと操作の権限をまとめたものです。①のロールを含まないパターンです。 |

## 構成パターン

構成要素①〜④の組み合わせにより、独自権限パターンを以下の6つに分類します。

| パターン | プロパティの構成 | 対象プロダクト |
|:---:|---|---|
| A | <span style={{ whiteSpace: 'nowrap' }}>①基本権限</span> | 従業員サーベイ、配置シミュレーション、スキル・資格・研修、HRアナリティクス |
| B | <span style={{ whiteSpace: 'nowrap' }}>①基本権限<br />②カスタム操作権限</span> | 人事評価 |
| C | <span style={{ whiteSpace: 'nowrap' }}>①基本権限<br />③独自オブジェクト権限</span> | キャリア台帳 |
| D | <span style={{ whiteSpace: 'nowrap' }}>①基本権限<br />②カスタム操作権限<br />③独自オブジェクト権限</span> | 対象プロダクトなし |
| E | <span style={{ whiteSpace: 'nowrap' }}>④ロールのない基本権限<br />③独自オブジェクト権限</span> | 社内公募 |
| F | <span style={{ whiteSpace: 'nowrap' }}>④ロールのない基本権限<br />②カスタム操作権限<br />③独自オブジェクト権限</span> | 採用管理 |

上記のうち、デザインパターンとしてガイドライン化しているのはA, B, Cの3つです。Dは現状で該当プロダクトがないため、EとFはロールを利用せず独自オブジェクトの設定が複雑なため、パターン化していません。

独自権限パターンの権限設定は「一覧画面」と「アカウントの詳細」の2つの画面で構成されます。それぞれのパターンは以下のページにまとめています。
