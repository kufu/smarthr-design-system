共通設定の権限とは切り離し、プロダクト独自にアカウントごとに権限を付与するパターンを説明します。

## 用語

このパターンで扱う用語の定義です。

| 用語 | 説明 |
|:---|---|
| 権限 | アカウントに付与するプロダクトの操作の許可のことです。権限は、アカウントに関連づける要素（操作の権限、ロール、独自の設定項目）の組み合わせで表します。 |
| 要素 | 権限を構成する各部品のことです。 |
| 構成 | 要素の組み合わせです。ロールの有無、操作の権限の種類、独自の設定項目の有無で表します。 |
| <span style={{ whiteSpace: 'nowrap' }}>画面設計</span> | 権限設定画面のレイアウトや利用するコンポーネントの設計です。[一覧画面](/products/design-patterns/permissions-settings/rbac-standalone/collection/)と[詳細画面](/products/design-patterns/permissions-settings/rbac-standalone/single/)があります。 |

用語で扱っている「ロール」は、一般名詞としてのロール（役割）やRBACが示す `Role` ではなく、**SmartHR基本機能の共通設定で管理している「ロール」のこと**です。

## 要素

権限がどのような要素で構成されるかを説明します。

- [アカウント](#h3-0)
- [操作の権限](#h3-1)
- [ロール](#h3-2)
- [独自の設定項目](#h3-3)

### アカウント

権限を付与する対象を「アカウント」と呼びます。メールアドレスアカウントまたは社員番号アカウントのことです。

テナントの従業員全員ではなく一部の管理者にだけ権限を付与するプロダクトでは、管理者権限を持つことを明確に認知させるため、アカウントを「管理アカウント」と呼び替えることがあります。

### 操作の権限

アカウントがプロダクトで何をできるかを決めるものです。アカウントに対して1つだけ設定できます。

#### 操作の権限の種類

操作の権限は、プロダクトがあらかじめ定義した操作の権限（プリセット操作権限）だけの場合と、それに加えてユーザーが作成した操作の権限（カスタム操作権限）も含まれる場合があります。

画面設計に関わるのでガイドライン上では呼び分けますが、プロダクトの画面上では分けて管理せず「操作の権限」としてまとめて扱います。

また、どちらの場合でもアカウントに設定できる操作の権限は1つです。

### ロール

アカウントがプロダクト内で閲覧できる従業員情報の範囲を絞るためのものです。共通設定のロールから1つ選択し、アカウントに関連づけます。

### 独自の設定項目

操作の権限やロール以外のプロダクト固有の設定項目で、アカウントごとに設定するものを指します。

テナントごとにプロダクト全体に適用する表示設定や通知設定など、アカウントと関係なく決まる設定は、独自の設定項目には含みません。

## 構成

要素の「アカウント」と「操作の権限」は必須です。ロール・カスタム操作権限・独自の設定項目は、プロダクトの要件に応じて追加します。

| <span style={{ whiteSpace: 'nowrap' }}>ロール</span> | <span style={{ whiteSpace: 'nowrap' }}>カスタム操作権限</span> | <span style={{ whiteSpace: 'nowrap' }}>独自の設定項目</span> | <span style={{ whiteSpace: 'nowrap' }}>対象プロダクト</span> |
|:---|:---|:---|:---|
| なし | なし | なし | &lt;ESP・情シスのプロダクト名&gt; |
| なし | なし | あり | 社内公募 |
| なし | あり | あり | 採用管理 |
| あり | なし | なし | 従業員サーベイ、配置シミュレーション、スキル・資格・研修、HRアナリティクス |
| あり | あり | なし | 人事評価 |
| あり | なし | あり | キャリア台帳 |
| あり | あり | あり | 対象プロダクトなし |
