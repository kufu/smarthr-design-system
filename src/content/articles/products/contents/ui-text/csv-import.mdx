CSVファイルを取り込んで、データを一括で追加・更新する画面のライティングについてまとめています。
ライティングは、[基本的な考え方](/products/contents/writing-style/)、[用字用語](/products/contents/idiomatic-usage/)に準拠します。
CSVファイルの取り込みによる一括操作の画面特有の気をつけるべきポイントと、ライティングパターンを記載しています。

## 基本的な考え方

ユーザーがやりたいことは、CSVファイルを取り込むことではなく、データを一括で追加したり更新したりすることです。CSVファイルはそのための手段です。
そのため、画面名などには「CSVファイル」よりも、ユーザーが実行する操作を優先して記載します。

また、この画面ではユーザーが手順にそって操作を進めることが最も重要です。説明文は簡潔にし、手順をわかりやすく書きましょう。

## 構成

CSVファイルの取り込みによる一括操作の画面は、以下の要素で構成されています。
- 画面名
- 説明文
- ファイルの呼び名
- 手順
- ボタン

## 画面名

- **「\{オブジェクト名\}の一括\{操作名\}」** を基本形とします。
    - [画面タイトルや項目名には名詞を使用する](/products/contents/ui-text/app-writing/#use-nouns-in-screen-titles-and-field-names)
- CSVファイルの取り込み以外にも一括操作の方法があるなど、手段がCSVファイルであることを強調したい場合は、末尾に「（CSVファイルの取り込み）」をつけても構いません。

### 例
- 従業員の一括更新
- 発令の一括追加（CSVファイルの取り込み）

## 説明文

- 説明文よりも手順のほうが重要なので、説明文は簡潔に書きます。
- ヘルプページへの動線は、[ヘルプページへの動線](/products/contents/ui-text/help-link/)に従います。

### 例
「CSVファイルを使って発令を一括追加します。詳しくは、<u>発令を一括で追加する</u>を参照してください。」

## ファイルの呼び名

- 画面上でダウンロードさせるファイルは、**「\{操作\}用ファイル」** を基本形とします。
    - 例：一括追加用ファイル、一括更新用ファイル
- 給与明細のように、設定した項目がファイルのヘッダーに反映されず、ダウンロードしたファイルをそのまま使えない場合は、**「ファイルの作成例」** とします。
- 「サンプルファイル」とは書きません。
    - 中身をイメージしづらいためです。また、[カタカナ語を用いるときには、まず漢字語での言い換えを検討する](/products/contents/writing-style/#prefer-kanji-to-katakana-words)にも反します。
- ダウンロードしたときのファイル名は、[ファイル名](/products/contents/ui-text/file/)に従います。

## 手順

### 見出し
- 操作手順であることが伝わるように書きます。
- 見出しの冒頭には、手順の順番を表す数字をつけます。
- 見出しは、「ファイルの編集」ではなく **「ファイルを編集」** のように、助詞「を」を使います。
    - 画面タイトルや項目名は名詞で表記しますが、手順の見出しはユーザーに求める操作を表すため、「を」を使って操作手順らしく書きます。
- 1つ目の手順の前に、設定項目などの手順が入ることもあります。

### 本文
- 見出しの下の本文には、どのようにファイルを編集・操作してほしいかを **「〜してください。」** の形で記載します。
- ファイルを編集するときの注意点には、必要に応じて以下を含めます。
    - 削除・編集してはいけない列
    - 入力の制限
    - セルを空欄にしたときの挙動
- 入力例は、[SpreadsheetTable](/products/components/spreadsheet-table/)を使って示します。
    - 入力項目が少ない場合などは、省略しても構いません。

## ボタン

- ファイルを取り込むボタンのラベルは、**「取り込む」** を基本形とします。
    - [ボタンラベルには動詞の終止形を使用する](/products/contents/ui-text/app-writing/#use-finite-verbs-in-button-labels)
- 削除などの破壊的な操作で、取り込んだあとの結果を強調したい場合のみ、「削除」のように操作をそのままラベルにしても構いません。

## ライティングパターン

| 要素 | ライティングパターン | 例 |
| ---- | ---- | ---- |
| 画面名 | `{オブジェクト名}の一括{操作名}` | 従業員の一括更新 |
| 画面名（手段を強調する場合） | `{オブジェクト名}の一括{操作名}（CSVファイルの取り込み）` | 発令の一括追加（CSVファイルの取り込み） |
| 説明文 | `CSVファイルを使って{操作対象}を一括{操作}します。詳しくは、{ヘルプページタイトル}を参照してください。` | CSVファイルを使って発令を一括追加します。詳しくは、<u>発令を一括で追加する</u>を参照してください。 |
| 手順1の見出し | `1. {操作}用ファイルをダウンロード` | 1. 一括追加用ファイルをダウンロード |
| 手順2の見出し | `2. ファイルを編集` | 2. ファイルを編集 |
| 手順2の本文 | `{入力してほしい内容・注意点}` | 追加する発令の情報を入力してください。 |
| 手順3の見出し | `3. ファイルを取り込む` | 3. ファイルを取り込む |
| 手順3の本文 | `編集したファイルを選択し、［取り込む］を押してください。` | 編集したファイルを選択し、［取り込む］を押してください。 |
| ボタン | `取り込む` | 取り込む |
